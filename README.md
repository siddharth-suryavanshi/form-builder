# JSON Form Renderer

This React/Vite project converts a JSON form definition into a working UI form.

## Run

```bash
npm install
npm run dev
```

## Change the form

Replace:

`src/forms/employee.json`

with your AI-generated JSON. The same DynamicForm component will render it.

Supported types:
- text
- number
- date
- textarea
- dropdown
- radio
- checkbox
- section
- label
